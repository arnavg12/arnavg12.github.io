Project 5

In Part A, I used a pretrained flow model to denoise, generate, and edit images, including text-guided edits, visual anagrams, and hybrid images. In Part B, I trained my own flow matching model on MNIST from scratch.

Project 5A: Exploring the Power of Flow Models

Constructing Noisy Training Inputs

I made noisy images by interpolating between Gaussian noise and my clean image using the formula xt = (1 − t)ε + t x. At t = 0, the image is pure noise, and at t = 1, it is the clean image.

Classical Denoising

As a baseline, I divided by t and applied a Gaussian blur, using stronger blur for noisier images. It removes most of the noise but removes image detail as well.

One-Step Denoising

Using the prompt a high quality photo, I predicted the velocity once and jumped straight to the clean image using the formula x̂1 = xt + (1 − t) v. It's far sharper than blurring, but it loses fine detail.

Visualizing Velocity

I compared the predicted update (1 − t) v with the true update (1 − t)(x − ε). They look almost identical. The error sits mostly along the edges and shrinks as t increases.

Iterative Denoising with Euler Sampling

Euler sampling takes small steps and predicts a new velocity after each one. Over 25 steps from t = 0.5 to 1, the noise fades and the penguin comes back almost exactly, including the fine detail one-step was missing.

Generating Images from Noise

Here, we start Euler sampling from pure noise at t = 0 to generate new images. Using the prompt a high quality photo, all five samples are portraits of people, so this generic prompt strongly favors faces. Some look realistic (182 and 184), but others are distorted or warped faces (180 and 183).

Classifier-Free Guidance

With classifier-free guidance (w = 7), I combine the conditional and unconditional velocities using the formula v = vu + w(vc − vu). Using the same starting noise, every image is now a clean and realistic face without distortion, but overall they're less varied and are all centered and front facing with similar lighting.

Image-to-Image Editing

Here, we add noise to a real image and then denoise it allowing the model to make edits. Smaller starting times add more noise and give bigger changes, while larger starting times stay closer to the original.

Editing Web and Hand-Drawn Images

This works especially well if we start with nonrealistic images and project them onto the natural image manifold.

Text-Guided Image Editing

Here, we perform the same editing process, but with custom prompts instead of a high quality photo, so the edit moves toward what the prompt describes.

Visual Anagrams

To create visual anagrams, at each step, I predict the velocity for one prompt on the image, and for a second prompt on the image rotated 180°. I rotate the second velocity back and average the two, so the result shows one prompt upright and the other upside down.

Hybrid Images

To create hybrid images, at each step, I combine the low frequencies of one prompt's velocity with the high frequencies of another's, using a Gaussian blur (kernel 265, σ = 16). Up close you see one prompt, and from far away you see the other.

Project 5B: Flow Matching from Scratch

Noising Process

Here, I made noisy images by adding Gaussian noise to clean digits using the formula z = x + σε. As σ increases, the digits become harder to see.

Single-Step Denoiser

I trained the UNet to remove noise at σ = 0.5 using an L2 loss, Adam with a learning rate of 1e-4, and batch size 256 for 5 epochs.

Out-of-Distribution Noise

Here, we observe testing on noise levels the model wasn't trained on (each pair of rows is the noisy input and the denoised output), still gives clean digits up to σ = 0.6 before the digits devolve.

Denoising Pure Noise

Here, I retrained the model with pure noise as input and found that every output is the same blurry gray shape no matter the input. Since pure noise tells the model nothing about the target digit, the MSE loss pushes it to predict the average of all training images, so it outputs the mean digit every time.

Time-Conditioned Flow Matching

Here, instead of denoising in one step, I trained a UNet to predict the flow from noise to a clean digit, conditioned on the timestep t. I used Adam at 1e-2 with an exponential learning rate decay.

After 1 epoch, the samples are just scribbles but by epoch 5, many are recognizable, and by epoch 10, most are legible digits, though some are still malformed since the model doesn't know which digit to draw.

Class-Conditioned Flow Matching

Here, I additionally conditioned the UNet on the digit class, dropping the class 10% of the time so it can still generate unconditionally.

Each row shows digits 0 through 9. Time and class conditioning converges much faster than time only: every digit is already roughly recognizable after 1 epoch, and by epochs 5 and 10, they are clean and sharp.
